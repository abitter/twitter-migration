# Open science endorsement: aggregate context (Supplementary Appendix 7)

`r2r_os_endorsement_context.py` reports, for the researchers flagged as endorsing open science,
which of the configured terms matched their profile description and which words most often
surround the match. Only aggregate counts are written (`table_os_endorsement_context.csv`); no
description or fragment is exported, because even short fragments can identify individuals.
Inputs are the final sample and the cleaned descriptions from the data deposit; paths are absolute.
